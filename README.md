# kNotes 📝

# Создана программа совместно с ИИ gemini.
Кроссплатформенная интерактивная база знаний и трекер прогресса (C++17 / Qt5 / SQLite3), полностью совместимая с **Obsidian** (Obsidian Flavored Markdown).


## 🚀 Возможности
- **Двусторонняя синхронизация с Obsidian:** любые `.md`-файлы и папки подхватываются автоматически в реальном времени.
- **Потоковые вложения:** файлы и картинки прикрепляются прямо в текст через `[[имя_файла]]` (как в Obsidian).
- **Контроль удалённых файлов:** если прикреплённый или встроенный файл удалён с диска, ссылка в тексте мгновенно подсвечивается **красным жирным шрифтом**.
- **Трекер прогресса:** визуальное отображение прогресса по главам и папкам с настраиваемой шкалой.
- **Подсветка синтаксиса:** поддержка Prism.js (более 300 языков программирования), формул LaTeX и диаграмм Mermaid.

## 📦 Скачать релизы
Готовые к использованию дистрибутивы под Windows и Linux доступны в разделе [GitHub Releases](../../releases):
- **`kNotes_Setup.exe`** — автоматический установщик для Windows 10/11.
- **`kNotes_Windows_Portable.zip`** — портативная версия для Windows (работает без установки).
- **`kNotes.deb`** — пакет для установки в дистрибутивах Linux (Ubuntu, Debian, Mint).

## 🛠 Сборка из исходников
